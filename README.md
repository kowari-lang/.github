# kowari-lang/.github

This repository holds the **organization profile** and **default
community health files** for the [Kowari](https://github.com/kowari-lang)
GitHub organization.

GitHub automatically uses the files here as defaults in any repository
in the organization that does not define its own copy. Editing these
files changes the contribution experience across the whole org.

- `profile/README.md` → the public organization page.
- `CONTRIBUTING.md` → contribution guidelines.
- `CODE_OF_CONDUCT.md` → community standards.
- `SECURITY.md` → vulnerability reporting.
- `ISSUE_TEMPLATE/` → default issue forms.
- `PULL_REQUEST_TEMPLATE.md` → default PR description.

The project itself lives at <https://github.com/kowari-lang/kowari>.
